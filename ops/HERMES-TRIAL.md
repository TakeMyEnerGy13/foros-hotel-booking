# Личный тест через Hermes

Рабочая копия отеля на тестовом сервере отделена от основной ветки GitHub. Оператор может менять в ней тексты, фотографии и вёрстку. Реальные заявки выключены. Оба тестовых адреса защищены паролем.

После изменения исходников оператор сохраняет правку локальным коммитом в рабочей копии сайта и выполняет `hotel-trial preview`. Команда собирает именно этот коммит и проверяет статический экспорт. На выходе она сообщает идентификаторы версий. Черновик можно открыть и проверить с телефона.

После одобрения оператор выполняет `hotel-trial publish <полный SHA просмотренного черновика>`. Сборка повторно не запускается. `hotel-trial status` показывает текущие версии. `hotel-trial rollback <полный SHA текущей публикации>` возвращает предыдущую опубликованную версию. История исходников сохраняется в Git на тестовом сервере.

Для переноса скрипта на другой Linux-сервер задайте `HOTEL_TRIAL_ROOT` с каталогами `source` (рабочая копия Git), `cache` и `site/releases` на одной файловой системе. Сборочному пользователю нужен доступ на чтение к исходникам, запись в два последних каталога, Python с поддержкой фильтра распаковки tar, Git, Node и npm. Веб-серверу требуется только чтение `site/live` и `site/draft`. Для передачи заказчице предусмотрите отдельного Telegram-бота и пользователя ОС с доступом только к этому проекту.
