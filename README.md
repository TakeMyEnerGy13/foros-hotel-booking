# Берег Радости

Сайт гостиницы в Форосе. Каталог находится в `/rooms`, гостевой календарь — в карточке номера, панель администратора — в `/admin`.

## Локальный запуск

Требуются Node.js 22 и PostgreSQL. Установите зависимости командой `npm ci`. В локальном файле `.env` задайте `DATABASE_URL` для отдельной базы гостиницы. Если задаёте адрес также в `.env.local`, используйте одну и ту же базу для CLI и сайта.

В `.env.local` задайте `ADMIN_PASSWORD` и случайный `ADMIN_SESSION_SECRET` длиной от 32 символов. Смена секрета завершает ранее выданные сессии. В production передайте значения через окружение и обслуживайте сайт по HTTPS.

1. Примените схему к базе разработки командой `npx prisma db push`.
2. Для пустой демонстрационной базы заполните четыре номера командой `node --experimental-strip-types prisma/seed.ts`. Скрипт заменяет номера и брони. Запускайте его только в пустой базе примеров.
3. Запустите `npm run dev` и откройте `http://127.0.0.1:3000`.

## Проверки

- `npm run lint` и `npm run build` проверяют исходники и production-сборку.
- Для `npm run test:bookings` запустите локальный сайт на отдельной базе с именем, заканчивающимся на `test` или `preview`. В `.env.local` укажите её `DATABASE_URL` и пароль администратора. При необходимости задайте `TEST_SITE_URL`. Тест создаёт собственный номер и удаляет свои данные после проверки.

Гость подаёт заявку в статусе `pending`. Заявки и подтверждённые брони занимают ночи с даты заезда до даты выезда. Администратор подтверждает или отменяет заявку. Отмена освобождает даты.
